# Cifra de César em C

Projeto académico desenvolvido em C com o objetivo de aplicar conceitos de criptografia, algoritmos, sequências matemáticas e manipulação de arquivos.

## Funcionalidades

- Criptografia através da Cifra de César;
- Utilização de um valor de SHIFT definido pelo utilizador;
- Aplicação de deslocamentos dinâmicos através de sequências matemáticas;
- Progressão Aritmética (PA);
- Progressão Geométrica (PG);
- Sequência de Fibonacci;
- Números Primos;
- Gravação do resultado da criptografia em arquivo;
- Registo da execução em arquivo;
- Visualização do último resultado;
- Visualização do log de execução;
- Organização do código em diferentes módulos.

## Tecnologias

- C
- Algoritmos
- Criptografia
- Sequências matemáticas
- Manipulação de arquivos
- Modularização
- Lógica de programação

## Estrutura do projeto

- `main.c` — programa principal e menu de interação;
- `criptografia.c` / `criptografia.h` — funções relacionadas à criptografia;
- `sequencias.c` / `sequencias.h` — geração das sequências matemáticas;
- `arquivos.c` / `arquivos.h` — leitura e gravação dos arquivos;
- `resultado_criptografia.txt` — resultado gerado pelo programa;
- `log_execucao.txt` — registo da execução;
- `README.md` — documentação do projeto.

## Contexto académico

Projeto desenvolvido no âmbito da disciplina de Algoritmo e Pensamento Computacional, no curso de Engenharia de Software.
